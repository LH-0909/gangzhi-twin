# 港智孪生业务服务

独立 FastAPI 服务，Python 3.12。仿真场景借鉴大连综合港业务，港区布局、货量、设备效率、天气约束与能耗系数均为竞赛演示设定。这里没有实港数据连接或生产控制接口。

## 本地运行

在 `backend` 目录执行：

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip --isolated install --no-user -r requirements-lock.txt
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8011
```

已有虚拟环境可直接运行最后一行。依赖源访问受限时，可给安装命令传入当前有效代理或可信镜像。`requirements-lock.txt` 是本次验证环境的完整版本快照，`requirements.txt` 是运行所需直接依赖，`requirements-dev.txt` 增加 API 客户端与测试工具。

文档：`http://127.0.0.1:8011/docs`。健康检查：`http://127.0.0.1:8011/api/health`。

## 业务状态与仿真

`GET /api/state` 返回唯一当前业务状态。服务端时钟每秒推进运行中的仿真，浏览器轮询不会额外推进时间。仿真初始暂停在 08:20，即种子 42 的初始场景经过 20 分钟实际计算后的状态；初始吞吐与能耗由上述计算产生。步进默认 60 秒。运行速度允许 1–120 倍。

4 个泊位检查船型与吃水，已有占用不能重复分配。船舶依次等待、靠泊、作业、离泊；任务进度直接投影自同一船舶状态。吞吐量从累计实体作业量投影，限制在已定义箱量范围内。设备能源按运行状态与仿真时间累积。岸电与冷链设备也纳入能耗，碳排放采用演示系数 `0.57 kgCO₂e/kWh`。

集装箱、冷藏箱船使用 `cargo_teu`；散粮、液体能源船使用 `cargo_tonnes` 且 `cargo_teu=0`。统一显示字段是 `cargo_amount` + `cargo_unit`（`TEU` 或 `t`）。三类完成货量分别返回 `kpis.throughput_teu`、`kpis.bulk_tonnes` 和 `kpis.liquid_tonnes`，不跨单位相加。每船 `arrived` 和 `eta_seconds` 可区分已到达的等泊船与未来预计到港船。

海雾延长靠泊并降低效率；大风会持续暂停岸桥，直到切换恢复场景；主干道封闭改变开放路网与运输效率；QC-02 故障降低 B01 作业能力。场景告警和等待告警带 `active` 字段，风险解除后保留历史记录，告警确认是幂等操作。当前未处理风险应统计 `active !== false && !acknowledged`。

SQLite 默认位于 `backend/data/gangzhi.sqlite3`，`GANGZHI_DB_PATH` 可覆盖。每次控制与运行中的每个服务端 tick 保存快照；重启恢复作业、任务、能耗、事件与告警，并暂停时钟等待操作员继续。恢复后不会自动把停机期间的现实时间加入仿真。实验结果保存在独立表中。

## 调度对照实验

`POST /api/experiments/compare` 接受种子、船数和扰动。两策略使用同一货量、到达时刻、吃水、优先级、开放道路和设备效率。本实验只包含集装箱/冷藏箱作业，统一单位为 TEU，返回 `model=container_dispatch_benchmark` 与 `total_cargo_teu`。实验使用三个可比较的抽象箱运泊位，便于观察不同分配策略；这与实时综合港场景的四个专用泊位是两个明确区分的实验模型。每艘船的计算时间线还含实际路径、往返次数、距离与能耗，可逐项复核汇总指标。

- 基线：已到达船舶先到先服务，分配空闲兼容泊位，车辆使用固定开放环线。
- 优化：在已到达船舶与空闲兼容泊位之间，按作业时间及优先级选择组合，车辆采用 A* 开放道路路径。
- 每次分配均检查吃水、到达时间与泊位占用；船舶不会在到达之前作业。
- 报告实际计算出的平均等待、最后完工时间、车辆总距离、能耗与完成数，返回相同 manifest 和各自逐船时间线。优化率允许为负，不预设收益。
- 实验天气为固定效率扰动，适合有限时长的对照评估；实时大风场景的暂停需要手动恢复，两者不混作同一模型。
- 模型能耗公式：`作业分钟 × 7.8 + 车辆公里 × 1.15 + 等待分钟 × 2.8`。这些是可修改的演示假设，不能用结果宣称真实港区节能率。

道路示意坐标以公里计，`GET /api/routes?blocked=true` 可检查关闭边和重新寻得的路径。A* 启发函数采用欧氏距离，路段权重也采用欧氏长度。

## 验证

```powershell
.venv\Scripts\python.exe -m pytest -q
```

测试覆盖种子复现、进度与库存守恒、泊位互斥、天气和设备故障对实际进度的影响、A* 禁行边、两方案输入公平性、调度吃水/时间/占用约束、SQLite 恢复、REST 控制、告警确认与无效输入。
