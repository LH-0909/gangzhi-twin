# V0.4：把一只箱的旅程接入三维港区

日期：2026-10-29。开发分支：`feature/realistic-port-world`。

## 可以实际使用的新增内容

- 船舶具有航道进港、锚地等待、引航靠泊、泊位作业和出港的空间过程。船位和航线由后端提供；出港船舶会沿航道驶离，再退出画面。
- 点击首页右侧“体验一只箱的港口旅程”，再选择“开始箱运演示”。系统绑定 B01 在泊箱船、QC-02 和 AGV-01，以 10× 速度开始演示。
- 示范箱 `GZTU9000017` 依次经过等待岸桥、卸船、运输、入堆、暂存、提箱、运输、闸口核验和出场。目标为 **C4-16-06-5**，位于原参考箱 `MSKU5809014` 的上一层。该箱位预留为空，不与静态库存重复占位。
- 可跟随箱子或车辆，定位关联船舶，点击已执行的阶段回放。作业记录可以导出为 JSON。
- QC-02 故障和大风会暂停相应吊装。道路封闭后，载箱车从当前位置退回安全路口，再通过米制道路图的 A* 路径绕行，避免瞬移。
- 时间轴提供暂停、1/10/30/60/120×、前后 30 秒、拖动、事件定位、近一小时/全部记录以及回到最新。日照和海面随同一仿真时钟变化。
- 顶栏“数据说明”展示模拟范围、计量口径、碳排系数和大连场景参考来源。

## 数据和模型的范围

本轮重点是 **1 只 40HC 的完整作业示范**。其他堆场箱、背景车辆、铁路和船载箱用于表达港区规模，不代表所有箱货已具备逐箱调度。港区吞吐、吨位和设备能耗来自汇总模型，单箱演示不额外累加一次港区吞吐，避免重复计数。

船舶航线和道路采用米制示意坐标。靠泊时长、速度、装卸效率、货量与能耗参数均为演示设定，尚未加入水动力、转弯半径、避碰、交通冲突消解或真实港口作业规程。已建模的是状态和资源约束的交互过程。

调度实验仍聚焦另一套集装箱/冷藏箱批次模型。其三处抽象泊位与综合港场景四个专用泊位并不等同，实验结果尚未直接投射到当前三维场景执行。

## 本机使用

双击根目录 `启动港智孪生.bat`。依赖已安装时可运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -SkipInstall -NoBrowser
```

界面 `http://127.0.0.1:5180/`，API 文档 `http://127.0.0.1:8011/docs`。查看原参考样例箱：`http://127.0.0.1:5180/yard/C4?c=MSKU5809014`。

建议先观察一次完整箱运，再回放“堆场暂存”阶段。若 B01 船舶已经离港，先重置本轮仿真，再开始新示范。重置会清空本轮时间记录，调度实验记录保留。

回放时注入新情境会以该时刻为起点改写后续仿真记录。原始旧版 SQLite 快照没有完整输入历史；升级时保留业务状态，并从该快照的时间开始记录，不编造升级前的回放。

## 大连场景的资料依据

- [交通运输部：大连打造东北对外开放海上门户](https://www.mot.gov.cn/xinwen/jiaotongyaowen/202607/t20260731_4210840.html)：支持综合港、多式联运、冷链和绿色港口的主题选择。
- [大连黄海港务：冷链物流](https://www.zhuangheport.com/Warehousing.html)：支持地区水产品冷链的业务背景。
- [中央气象台：近海海雾预报](https://m.nmc.cn/publish/taifenghaiyang/jinhaihaiwuyubao/index.html)：作为海雾情境和后续海况接入的公开信息入口。

以上是题材参考，当前未接入这些机构的实时数据，也未将其公开业务规模直接代入模型。三维素材来源见 `THIRD_PARTY_NOTICES.md` 及资产目录中的 `sources.json`。
