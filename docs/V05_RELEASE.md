# V0.5 更新说明

港智孪生是使用模拟数据的竞赛原型；港区并非真实港口的实测地理或设备模型。

## 船舶与靠泊

旧版靠泊动画在靠近岸壁时仍按路线转向，长船体会扫过岸壁；多船通道共用也可能相交。本版明确船体中心、宽度、吃水和水面，用泊位护舷边界与示意间距求解船位。船上货物保持船体子对象，前后端共用船体外形与导航姿态。靠离泊通过同一通道串行调度；航线获准前以 5 秒间隔、附加示意裕度检查船体轮廓与岸壁、防波堤及其他船舶的关系。离港船舶不再显示在港区。

碰撞测试是离散采样而非连续扫掠证明；范围主要为水线处船体、码头和防波堤的简化几何，不覆盖桥吊、上层建筑、拖轮或真实航行安全。数值与轨迹是演示假设。

## 场景与扰动

散货区增加输送结构，液货区增加管线，流动物料标记按对应船舶的后端作业时钟运行，作为汇总作业的可视化，并非物料守恒或单颗粒仿真。大风会影响散货作业和相关岸桥；航道关闭阻止新的靠离泊安排，已经开始的船舶先通过。道路阻断、岸桥故障与海雾仍有各自影响。

新增大连海产品主题冷链演示：冷机故障改变温度、设备状态与告警，记录阈值以上时长；温度曲线和参数均为模拟，不能用于食品安全判断。

## 记录和算法

模拟状态、事件及回放共享时钟。旧模型记录在升级或重置时先归档，可在数据说明中下载；同版本记录支持恢复。旧版本记录不直接在新模型重放，需要使用对应版本。

调度对照在三个抽象集装箱泊位上运行，独立于四泊位综合港三维仿真；两方案使用相同输入、随机种子及约束。导出包含逐船未舍入时间、距离和能耗及指标口径，便于复算。结果允许为负，不能直接等同于真实港口收益。航道关闭目前不纳入该独立对照实验。

## 视觉和竞赛边界

已参照用户提供的 [智慧港口视频](https://www.bilibili.com/video/BV1bc411B7F6/)观察全景、桥吊近景和四类业务展示；具体观察与下一步设计见 [参考分析](VIDEO_REFERENCE.md)。本版仍为程序化三维模型，尚未达到视频或照片的写实质量；当前环境未完成新版 GPU 画面核查。真实传感器、完整多箱物流、直播视频、调度结果直接驱动实时港区、连续碰撞证明和完整竞赛演示视频均待后续完成。
